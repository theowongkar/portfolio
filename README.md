## 🛠️ Installation and Setup

1. Clone repository:

   ```bash
   git clone https://github.com/theowongkar/portfolio.git
   cd portfolio
   ```

2. Install dependencies:

   ```bash
   npm install && npm run build
   ```

3. Run local server:

   ```bash
   npm run dev
   ```

4. Open the browser and access http://localhost:5173
